## 🌑 Sobre la Asignatura
Programación Avanzada es el espacio donde la lógica y el desarrollo de software se unen. Esta materia se enfoca en la resolución de problemas complejos mediante código, optimizando procesos y creando algoritmos aplicables a la automatización, el monitoreo y los sistemas físicos.

## 📂 Portafolio de Evidencias
Este repositorio está diseñado como un **portafolio digital vivo**. Su propósito es documentar y respaldar mi progreso a lo largo del semestre. Aquí se almacenan todas las prácticas, simulaciones y ejercicios desarrollados en clase (como el análisis y monitoreo de motores), manteniendo un registro limpio de mi evolución en la escritura de código.
